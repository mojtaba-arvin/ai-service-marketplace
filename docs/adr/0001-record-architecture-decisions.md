# ADR 0001: Record Architecture Decisions

- Status: Accepted
- Date: 2026-11-19

## Context
This is a long-lived open-source platform developed by multiple human and AI contributors. Architectural decisions must remain reviewable and their rationale must survive model/session changes.

## Decision
Record material architecture decisions as numbered ADRs with status, context, decision, consequences, and alternatives considered. Do not silently rewrite accepted decisions; supersede them with a new ADR.

## Consequences
Architecture changes have an explicit review trail. Contributors can distinguish current decisions from proposals.

## Alternatives considered
- Informal chat-only decisions: rejected because they are not durable or auditable.
- One continuously rewritten architecture document: rejected because it obscures decision history.
